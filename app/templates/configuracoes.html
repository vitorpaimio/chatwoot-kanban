Situação

Atributos do contato

Atributos personalizados do Chatwoot usados em Métricas. Informe a chave do atributo (por exemplo, origem) ou deixe vazio para não usar.

Motivos de perda

Opções pedidas ao mover uma negociação para uma etapa de perda, um motivo por linha. "Outro", com descrição, fica sempre disponível.

Importação de contatos

Traz os contatos do Chatwoot para o Pipeline. Etapas e tarefas existentes são mantidas, e negociações não são duplicadas.

O que importar

Token de acesso

Token de um administrador desta conta, usado pelo Pipeline para falar com o Chatwoot. No Chatwoot, abra Configurações do Perfil e copie o Token de acesso. Ele é guardado criptografado.

Desativar o Pipeline

O quadro deixa de funcionar nesta conta. Funis, etapas, negociações e tarefas continuam salvos; para reativar, informe o token de acesso no Kanban.

Detalhes técnicos

Recursos que o Pipeline registrou no Chatwoot desta conta. Reaplicar a configuração refaz atributos e webhook sem apagar dados.

    Desativar o Pipeline?

    O quadro, as tarefas e as métricas ficam indisponíveis nesta conta até alguém reativar com o token de acesso. Nenhum dado é apagado.
